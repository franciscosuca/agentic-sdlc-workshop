# Workshop Application Rules

> Workshop based on: https://github.com/danielmeppiel/agentic-sdlc-handbook

Your application must address the following points:

1. What you explored, built, or changed
    - exan: ai based tool for scanning documents and making corrections (definition of system prompts to analyze files and create the expected output for the user by mixing the provider-schema and the software-schema)
    - exan: rely on an orchestrator methodology to delegate tasks to blind-implementer and oracle-tester
    - prompt-pack: for storing different agents, and skills that can be used cross-projects to enhance token ouput quality and reduce token consumption
    - general: rely on cloud agents build "on the fly" or unsupervised code implementation
    - lllm: use local llm for assesing its use for local agentic development

2. What you learned, including challenges or limitations
    - learned: agents customization for saving tokens and improving output of the prompts; definition of skills to decrease redundancy of usage for tokens; setup and assessments of local models to determine what workload can this take away from gh copilot
    - challenges: exploration of possible solutions or unsupervised code creation
    - limitations: using lllm for agentic development

3. Why you want to join the workshop
    - bcs I already started reading the book and I feel that I need more guidence to organize or structure what I have learned so I can use that knowledge to share it within my team and colleagues at work.
